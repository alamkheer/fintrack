# FinTrack

A premium, offline-first personal budget manager built with a **Digital Parchment** aesthetic.

## ✨ Features
- **Dashboard**: Real-time spending overview and insights.
- **Smart Entry**: Keyboard-first expense logging with autocomplete.
- **Spending Trends**: Visual analytics using lazy-loaded charts.
- **Offline-First**: Powered by IndexedDB for local data persistence.
- **Editorial Design**: High-end typography and sleek "Digital Parchment" UI.

## 🚀 Getting Started

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Run Development Server**
   ```bash
   npm run dev
   ```

3. **Build for Production**
   ```bash
   npm run build
   ```

## 🛠️ Tech Stack
- **Framework**: React + TypeScript + Vite
- **Storage**: IndexedDB (local-first)
- **Styling**: Tailwind CSS (Digital Parchment Tokens)
- **Charts**: Recharts (Lazy-loaded)
